# Brand on GitHub

Follows the official Smart Choice visual identity. Do not redraw the logo or introduce other accent colors.

## Colors

| Token | Hex | Use |
|---|---|---|
| Olive green | `#141D00` | Backgrounds, dark badges |
| Deep green | `#1E2D00` | Surfaces, cards |
| Medium green | `#2B780C` | Primary accent, filled elements with white text |
| Vivid green | `#52A00B` | Lines, icons, highlights — not behind small white text |
| White | `#FFFFFF` | Logo and text on green |

## Typography

All GitHub surfaces are in English and use **Inter**. GitHub does not load web fonts inside images, so all text in the SVG assets is converted to outlines.

## Assets

All in `profile/assets/`.

| File | Use |
|---|---|
| `avatar.png` · `avatar.svg` | Organization avatar |
| `banner.svg` | Organization profile header |
| `workflow.svg` | Delivery flow diagram |
| `social-preview.png` | Repository social preview (1280×640) |
| `logo-mark-white.svg` | Logo mark for dark backgrounds |
| `logo-mark-green.svg` | Logo mark for light backgrounds |

## Settings applied in the GitHub UI

These cannot be set from this repository:

- **Avatar:** Organization *Settings → Profile → Profile picture* → upload `avatar.png`.
- **Social preview:** Repository *Settings → General → Social preview* → upload `social-preview.png`.
